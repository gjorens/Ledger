Tools
Recurring items

Recurring items are created with + New item by choosing a repeat. The amount is an estimate. When the biller tells you the real amount, press Edit on that month's projected row to confirm it (it then shows in bold). If you know the amount will change from a certain date, use the calendar icon (Change amount from a date). To correct a mistake in the item itself, use its pencil. If the first date was in the past, those occurrences show as Due so you can post or skip them.

Monthly reconciliation

Tick each item that appears on the statement. Items not ticked can be edited here and carry over to the next month if they stay unticked.

Where your ledger file is kept

Choose the folder where your ledger lives: iCloud Drive, Dropbox, OneDrive or any other folder on this computer. The app saves ledger.json inside it and autosaves there. To make a new folder, type a name below first; it is created inside the folder you pick.

Browsers only tell the app the name of the folder you chose, not its full path.

Used only in the reminders shown when you save. The app cannot see where your phone puts a saved file, so it asks you to confirm. This is kept on this device, not in the ledger file, so each device can name its own folder.

Start a new ledger

Begin an empty ledger (for example your first real one after trying the test data). The file you have open now is not changed or deleted. The new ledger is saved as ledger.json.

Archive old data

Over the years the ledger file grows. Archiving moves old reconciled entries (and deleted ones) into a separate file, ledger-archive-YYYY-MM.json, and keeps balances exactly as they are. Nothing is lost: open the archive any time with View an archive…. Entries from the latest reconciled month, and anything not yet reconciled, always stay in your ledger.

A personal bank-transaction ledger that runs entirely on your device. Your data is only ever stored in the file you choose and in a safety copy inside this browser; nothing is sent anywhere.

User guide

Getting started

  • First time: tap Create first account, or use the file icon at the top and choose Open a file to load a ledger you already have.
  • Add more accounts with the + button beside Accounts (chequing, savings, credit card, loan, and so on). The pencil button edits the selected account: it changes its details, opening balance and low-balance warning.
  • Switch accounts with the tabs. Each account has its own balance, recurring items and reconciliation.

Adding items (+ New item)

  • Type: a payment or deposit, or a transfer between two of your accounts (it creates matching entries in both).
  • Repeats: choose weekly, every 2 weeks, monthly, every 3 months or yearly to make a recurring item. The amount is then an estimate.
  • Amounts: type digits only; the decimal point is fixed (1 2 5 0 gives 12.50). The ± button, or typing a minus sign, switches between money in and money out. On a credit card or loan, + means a charge and − means a payment.
  • Start typing a description to pick an earlier one; its category and amount are filled in.
  • Add another keeps the window open and the date unchanged, which is handy for entering a statement. "Repeats" goes back to "Does not repeat". If an amount looks the wrong way round for its category (money in for an expense, money out for income) you are asked to confirm.

The transaction list

  • Sorted by date, then credits before debits, then description. The list opens at your latest past transaction.
  • Edit changes any entry. Delete marks it deleted: it stays in the file but no longer counts.
  • Italic rows are projected from recurring items. est. means estimated. Edit a projected row to change that one occurrence only: enter your own estimate (for example a big purchase coming up) or the amount the biller confirmed, which then shows in bold. The other months keep the regular estimate. To change every following month use the calendar icon in Recurring items.
  • Each account can have a currency (CAD, USD, EUR, GBP, MXN and others) in Edit account. Balances then show with the right symbol. There is no conversion between currencies, so a transfer between accounts in different currencies asks you to confirm, and reports across mixed-currency accounts carry a warning.
  • Transfers are described automatically as From account \u2192 To account and the description cannot be edited (it follows account renames). Amounts are positive only: use the double-arrow button between the two account boxes to swap the direction.
  • Starting your real ledger: File icon > Start a new ledger. The test file is left as it is; the new ledger saves as ledger.json.
  • Search (magnifier next to New item) lists matching entries by description, category, amount, date or account (this account or all). The target button on a result scrolls the ledger to that entry and flashes it; Back to ledger closes without moving. Show items exceeding threshold lists every item after which the balance is below the warning level (below zero if none is set). Negative amounts are red. Month bars in the list make it easier to find your place.
  • Archive old data (file icon) moves old reconciled entries into a separate file, ledger-archive-YYYY-MM.json, so your ledger stays small. Balances do not change. Open an archive any time with View an archive (read-only, searchable). Keep the archive files with your ledger: they are the only copy of those entries.
  • Row buttons are icons (hover for the name): pencil = Edit, trash = Delete, check = Post, skip arrow = Skip, back arrow = Unpost, square = Stop. A deleted entry stays in the list marked deleted with a round arrow button to undelete it (a transfer comes back on both sides).
  • Post turns a projected row into a real entry; Skip drops that one occurrence. If you post by mistake, press Unpost on the entry to put it back.
  • In Recurring items: the pencil edits the item (fix a wrong amount, description, category, dates, how often it repeats or the accounts of a transfer); the calendar icon schedules a new estimate from a future date; Stop ends the item. Once entries from an item have been posted, its first date and how often it repeats are locked. Items whose last date has passed, and stopped items, move to Finished and stopped items, where you can restore, continue (set a new last date) or remove them; Clean up removes the ones that have no entries in the file.
  • Look ahead sets how far projections run. Balance graph compares the 12 months ending at that date with the same 12 months a year earlier.

Monthly reconciliation

  • Open Monthly reconciliation, pick the statement month, enter the closing balance from your bank statement, and tick every item that appears on it.
  • When the difference is zero, press Mark month reconciled. Use Edit on unticked items, or Add missed item for something on the statement that is not in your ledger.
  • After the first reconciled month, balances count from the latest statement balance; the opening balance is only the starting point until then.

Credit cards and loans

  • These show the amount owing as a positive number, charges as positive and payments as negative. Behind the scenes the numbers are stored the same way as other accounts.

Low-balance warning

  • Set a level in Edit account. If a change makes a future balance drop below it, a popup appears and the account tab gets a red ring for as long as that stays true. For a card, the level is an amount owing that you do not want to exceed.

Reports

  • Open Reports to see spending and income by category (or by category and month) for a period you choose, for one account or all of them. Transfers, deleted items and projections are left out.

Saving

  • Chrome or Edge on a Mac: use the file icon at the top to choose a folder. The app then autosaves to it every 30 seconds and when you leave the page. If it asks you to Reconnect after a restart, tap it once.
  • Brave on a Mac (and other browsers that cannot write to a folder): Save file downloads the file to your Downloads folder, and you open the file from your ledger folder with Open a file. The optional Mac Automator folder action moves the download into your iCloud folder for you and keeps dated backups.
  • One folder on a Mac: pick one ledger folder and use it everywhere. The app itself does not know about the Automator script, but the script copies files to the one folder written inside it (for example iCloud Drive › myLedger). If you use the script, open and save in that same folder, or you may open an old copy. Saving straight into a folder from Chrome or Edge bypasses the script, so those saves get no dated backups. If you only use Chrome or Edge you do not need the script, but then nothing makes dated backups for you.
  • Safari, iPhone and iPad: press Save file (or Save to Files) after making changes, choose the folder, and choose Replace. Use the file icon, then Open a file, to load your ledger on another device.
  • An unsaved-changes banner shows when there is anything not yet saved. A safety copy is also kept inside the browser.
  • Use the same version of the app on all your devices, and open the latest file before you start entering items.

Test data

  • To practise without touching your real ledger, open ledger-test.json. The file is marked as test data inside itself, so the app shows an orange stripe and a TEST DATA tag whenever it is open, on any device. (A file named like test data but not marked asks you to confirm once, then is marked.) It is saved under the same name.
